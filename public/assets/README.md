# Recursos estáticos

Coloca aquí recursos públicos aprobados desde Figma:

- `brand/`: logo principal, isotipo y variantes SVG optimizadas.
- `icons/`: iconos SVG propios.
- `images/`: fotografías y gráficos WebP/AVIF.
- `fonts/`: tipografías con licencia para distribución web.

No guardes secretos, datos personales ni exportaciones de Figma sin optimizar.
Prefiere SVG para logo/iconos y AVIF/WebP para imágenes. Cuando se agregue el
logo definitivo, úsalo desde `/assets/brand/...` en `ui-brand`.

## Tipografías del Brand Guide

- `Inter`: texto de interfaz, pesos 400 y 500.
- `Poppins`: títulos y etiquetas, pesos 400 y 600.
- `Geist`: peso 600 cuando el diseño lo requiera.

Se sirven localmente: no se cargan desde Google Fonts ni otro CDN.
